# Open Stall PRD
## Promise
Find the nearest usable restroom quickly and know what to expect before arriving.

## v1
U.S. first. iOS, Android, responsive web. Map + distance-sorted list. Find Nearest Restroom CTA. Show name, distance, ETA when available, 1–5 rating, verification and key access facts. Walk/drive/bike. Navigate via Apple/Google Maps.

## Modes
Plain: stars/clean language. Risqué ("Crapper Mapper"): playful copy/poop rating visual. Default Plain. Store numeric 1–5 regardless.

## Filters
Rating, radius, wheelchair accessible, gender-neutral, baby changing, hot/warm water, cold-water-only, key required, purchase required/free, verified-only. Do not paywall urgent accessibility/access facts.

## Data
Stable attributes: accessibility, gender-neutral, baby changing, hot/cold water, key, purchase, access location. Transient reports: dirty, broken/out, unavailable, incorrect info, safety concern, closed. No user photos.

## Verification
Preload public/commercial candidates. User additions/edits stay pending until admin approval. Protect against private residences/malicious submissions. Status: verified/pending/closed. Track last verification.

## Accounts
Email/password, Google, Apple. Evaluate Yahoo SSO before implementing if disproportionate complexity. Cross-device sync; hidden email; deletion.

## Favorites
Free 5; premium unlimited.

## Gamification
Points reference: check-in +5, quality review +10, approved add +25, accepted helpful report +10, referral +50 each subject to abuse controls. Achievements/weekly/all-time leaderboard/community activity. Do not reward unhealthy/excessive check-ins; redesign/omit "Dethroned" unless approved.

## Monetization
Free with ads. Premium removes ads, unlimited favorites, richer amenity breakdown/history. Apple/Google mobile billing; Stripe web. PayPal optional/deferred. Never activate spend without approval.

## Notifications
Opt-in nearby verified restroom, achievements, approvals, weekly recap. Avoid intrusive tracking.

## Admin
Separate web admin: moderation, edit, duplicate merge, reports, rewards, CSV import/export, analytics/heatmaps, basic ad toggle.

## Analytics
Privacy-conscious aggregate search, density, time-to-navigation, filters, taps, navigation starts, ratings, reports, DAU/WAU.

## MVP success
User can find nearby restroom, understand access, navigate and submit correction; admin must approve before contribution is public.
