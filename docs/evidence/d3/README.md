Generated by `node scripts/visual-packet-d3.mjs` from the CURRENT source against the local QA mock (realistic fixture names, no real backend, no tiles host). Browser screenshots in EMULATED viewports only: this is NOT native, iPhone, VoiceOver or TalkBack evidence. Text enlargement shown here is a CSS emulation, not OS text scaling.
